# Игра Card Adventure
![Card Adventure](https://github.com/Igor20099/fantasy-card-game/blob/main/Screenshot_5.png)

Игра где вы передвигаете картой героя на карты врагов тем самым зарабатывая очки. В игре реализован **Drag and Drop**. Игра сделана на движке **Defold**

Поиграть можно здесь [joymaker123.itch.io/card-adventure](https://joymaker123.itch.io/card-adventure)
